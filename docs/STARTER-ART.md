# Starter workshop artwork

Created with the built-in image generation tool, 8 November 2026. Original assets preserved.

- `assets/garage-before-empty-v2.webp`: edit `garage-before.webp`; remove only the orange sports car, reveal the empty service bay, preserve blue lift rails, yellow arms, distressed room, furniture, lighting and doorway.
- `assets/safehouse-empty-v2.webp`: edit `safehouse-interior.webp`; remove only the orange sports car, preserve the restored workshop and empty service bay.
- `assets/starter-bomb-v2.webp`: realistic orthographic overhead sprite of a battered grey-green 1980s hatchback, beige mismatched bonnet and door, rust and dents, steel wheels, front pointing right, transparent background, no racing accessories. Refinement: strictly vertical camera, symmetrical projection with no visible wheel faces or door sides, no floor or drop shadow.

The game draws the selected owned car into the service bay dynamically, so the background cannot imply ownership of an expensive car. The same starter sprite appears in the street and garage selector.
